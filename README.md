# Water Sports Rental Sales Dashboard

An interactive Excel dashboard analyzing 2026 water sports rental sales, built with PivotTables, charts, and slicers.

## Key Metrics
- **Total Revenue:** $169,963.46
- **Total Rentals:** 3,300
- **Average Rental Revenue:** $51.50
- **Peak Month:** July

## Dashboard Features
- Sales trend over time (monthly)
- Customer type mix (Walk-in, Online Booking, Resort Guest, Group/Event, Member)
- Sales by team member
- Top 5 rental items by revenue
- Team Member slicer for interactive filtering

## Key Insights
- Sales peak in July and are strongly seasonal, with the summer months driving most revenue.
- Walk-in (33.3%) and Online Booking (31.1%) make up nearly two thirds of rentals.
- Stand-Up Paddle Boards, Single Kayaks, and Tandem Kayaks are the top revenue items.

## Tools Used
Microsoft Excel (PivotTables, PivotCharts, Slicers, KPI cards)
